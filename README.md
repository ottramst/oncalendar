# oncalendar

Parse, normalize, describe and evaluate systemd
[`OnCalendar=`](https://www.freedesktop.org/software/systemd/man/latest/systemd.time.html#Calendar%20Events)
expressions in JavaScript and TypeScript, with the same results as `systemd-analyze calendar`. Zero
dependencies; runs in Node.js and browsers, with full IANA timezone and DST support.

> **Status:** early development. The API below is the plan, not yet implemented.

```ts
import { describe, next, normalize } from 'oncalendar'

normalize('Mon..Fri 9:00 Europe/Tallinn') // 'Mon..Fri *-*-* 09:00:00 Europe/Tallinn'
describe('Mon..Fri 9:00 Europe/Tallinn') // 'Every Monday to Friday at 09:00 (Europe/Tallinn)'
next('*-*~01 23:00', { count: 3 }) // last day of each month at 23:00
```

## Why

systemd timers are a great cron replacement, but the only way to check an `OnCalendar=` expression has been
`systemd-analyze calendar` on a Linux machine. This library brings the same parser and next-elapse logic to
any JavaScript runtime, so you can validate timers in CI, editors, dashboards and the browser.

## Correctness

Expected results are generated by running `systemd-analyze calendar` itself across several systemd versions
(see [scripts/golden/](scripts/golden/README.md)), including DST transitions, end-of-month (`~`) expressions
and fractional seconds.
